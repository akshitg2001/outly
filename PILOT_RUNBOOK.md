# Outly controlled pilot runbook

## Cohort shape

- Start with one observed group of 3–4 people.
- If that journey completes without a critical defect, invite two more groups.
- Cap the first cohort at 10 people across 2–3 outings.
- Ask each person to use their own device and normal starting location.

## Founder checklist

1. Create an outing with two or more candidate dates.
2. Share only the participant link; keep the organizer link private.
3. Confirm every invited person can submit or edit independently.
4. Review the shared brief and resolve any proposed adjustment.
5. Lock the brief and generate plans.
6. Check the time, travel, cost caveats, activity-to-food transfer and restaurant alternatives before sharing results.
7. Ask participants to vote, then select the final plan as organizer.
8. Ask every participant to submit the usefulness and reuse questions.
9. Record any confusing screen, illogical plan, missing venue or incorrect external link in the pilot issue log.
10. Run the privacy cleanup from the admin dashboard at the end of each pilot day.

## Stop conditions

Pause new invitations if any of these occur:

- another participant's exact origin or budget becomes visible;
- a plan exceeds an accepted travel or known-cost ceiling;
- a venue, opening time or external link is fabricated or clearly wrong;
- submissions cannot be edited or concurrent responses overwrite each other;
- the same critical journey failure occurs twice.

## Pilot questions

After selection, ask the group:

- Did this save meaningful planning time?
- Was the final choice acceptable to everyone?
- Which recommendation felt illogical, and why?
- Would you use Outly for another outing?
- Did the external links make booking easier?
